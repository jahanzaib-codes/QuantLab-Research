# Changelog

All notable changes to **QuantLab-Research** are documented in this file.

## [1.0.0] - 2026-11-12
### Added
- Systematic Alpha Factor framework (Momentum, Low Volatility Anomaly, Short-term Reversal).
- Spearman Rank Information Coefficient (IC), Information Ratio (IR), and t-statistic metrics.
- Engle-Granger two-step cointegration engine with ADF stationarity testing.
- Ornstein-Uhlenbeck continuous-time mean-reversion half-life estimator.
- Multi-regime market classifier (Bull Trend, Bear Trend, Low Vol Range, Crisis Vol).
- High-performance vectorized pairs trading backtester with slippage and commission friction.
- Jupyter research notebooks for Pairs Trading and Cross-Sectional Alpha.
- Interactive terminal research CLI (`python cli.py demo`).
- Multi-stage Docker containerization and GitHub Actions automated CI matrix.
